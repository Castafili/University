## Mobile Network Evolution

$\text{1}^{st}$ Generation:
- Analogue mobile phone
- Low quality speech + low speed data (2.4 kbps)

$\text{2}^{nd}$ Generation:
- Digital mobile
- Digital voice + low speed data (9.6 kbps)

2.5 Generation:
- Packet switching data + Internet access
- Higher data rates

$\text{3}^{rd}$ Generation:
- (digital) Multimedia
- Higher data-rate (144 kb/s)
- Interoperation with 2G

$\text{4}^{th}$ Generation:
- Seamless High-speed wireless internet access
- Short range, High capacity

$\text{5}^{th}$ Generation: 
- Heterogenous small cells
- mmWave
- Network Slicing, Network Function Virtualization (NFV)

## Wired vs. Wireless

| Wired                     | Wireless                   |
| ------------------------- | -------------------------- |
| Low Attenuation           | High Attenuation           |
| No Interference           | Variable Interference      |
| Low Bit Error Probability | High Bit Error Probability |
| High Deployment Cost      | Low Deployment Cost        |
