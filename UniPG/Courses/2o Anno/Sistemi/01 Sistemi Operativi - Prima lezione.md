## Concetti base di Unix

- multitasking e multiuser: multitasking, l'utilizzo di più eseguibili allo stesso tempo
- modulare: non un singolo sistema ma vari "parti":
	- kernel, fornisce servizi di base
	- shell. interazione utente-sistema
	- utility, svolgono compiti semplici e possono essere combinate (pipeline) per eseguirne di meno semplici
- fatto per
- ++
- shell fornisce linguaggio scripting
- file system gerarchico con UNA root
- file memorizzati in plain text


## GNU/Linux

- Discendente di Unix (Unix-like)
- Famiglia open source di os Unix-like
- Piu corretto di parlare del os GNU/Linux
- POSIX compatibile, NON POSIX-certified
- Varie distribuzioni


## macOS

- gruppo os Apple
- Sistema proprietario
- Sono Unix-like ma sopratutto Unix-certified
