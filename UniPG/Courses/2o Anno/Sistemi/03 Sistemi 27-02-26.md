## Titolo

BASH:
- Programma che gira in spazio utente
- Espone "prompt" ed attende l "linea di commando"
- Interpreta ed esegue la linea
- Ne attende un'altra linea
- Termina con *exit* o *EOF* (ctrl + d)


Organizzazione dei file in un OS è, solitamente, fatta ad albero rovesciato con cartella principale **root** (/)

Tutti i progetti hanno una directory *ricorrente*

## Comandi

```sh
cd Percorso_Cartella # Cambio cartella

ls # Visualizzazione cartelle

df -h # Vedo i filesystem montati (-h mostra le dimensioni in modi piu leggibili)

sudo # Per eseguire un commando con i permessi di root

umount Percorso_Cartella # Per togliere in modo sicuro un disco esterno

mount Percorso_Cartella # Per rimettere in modo sicuro un disco esterno
```

In windows una chiavetta rimane a se stante, in linux viene aggiunta sotto ad una cartella già esistente, riconducibile alla root


## Navigazione filesystem

- Ogni processo ha una directory corrente
- Pathname assoluto:
	- Ogni oggetto nel filesystem e univocamente determinato dal percorso che dalla root porta all'oggetto stesso. I pathname assoluti cominciano sempre con **/** (es. :/etc/hosts/home)
- Pathname relativo: 
	- percorso che porta all'oggetto a partire dalla dir corrente (o cmq da un certo punto del filesystem)
- Nei pathname **.** è la dir corrente
- **..** è la directory *padre*, ovvero quella che contiene la dir corrente
